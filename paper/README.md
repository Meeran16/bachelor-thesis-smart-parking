# Source Project Report

The complete 2021 source-code folder is no longer available.

This GitHub repository was reconstructed from the preserved final project report:

**Smart Parking — Bachelor of Engineering in Computer Science and Engineering, Kumaraguru College of Technology, May 2021**

The report documents:

- the system workflow,
- the ANPR preprocessing pipeline,
- the booking-interface screenshots,
- the software/hardware stack,
- ANPR source code in the appendix,
- an IP-camera implementation snippet.

The complete Flask/MongoDB booking-application code was not included in the appendix and is therefore not reconstructed here.

The original PDF is intentionally not bundled in this repository package.
